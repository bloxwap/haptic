## Status

Planning is complete. Implementation and the first npm release are tracked in the [release plan](https://github.com/bloxwap/haptic/issues/1).

The planned package is `@bloxwap/haptic`. It will preserve the current public API of [joeblau/haptic](https://github.com/joeblau/haptic), with the library in `packages/haptic` and the documentation and interactive demos in `apps/docs`.

## Evaluation

The [assessment](.github/planning/EVALUATION.md) records the public API, platform behavior, clean-room boundaries, Bloxwap conventions, and the evidence required for release. The [task index](.github/planning/TASKS.md) links the implementation and publishing work.
